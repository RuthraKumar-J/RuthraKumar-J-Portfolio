## 💻 Getting Started Locally

### 1. Install dependencies
```bash
npm install
```

### 2. Run locally
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```
Production assets are generated in `dist/`, ready for zero-config deployment on Vercel, Netlify, or GitHub Pages.
